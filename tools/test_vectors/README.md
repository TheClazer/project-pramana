# Test vectors

Generated by:

```powershell
python -m tools.cli_sealverify.main vectors --out tools/test_vectors/
```

Files (regenerable, but committed to pin the cross-language contract):

| File | Purpose |
|---|---|
| `test_public_key.b64` | Deterministic ECDSA-P256 public key (DER, base64). |
| `manifest_NNN.input.json` | Pre-canonical manifest, signature blanked. |
| `manifest_NNN.canonical.json` | JCS canonical bytes (the bytes that get signed). |
| `manifest_NNN.signature.b64` | ECDSA-SHA256 over the canonical bytes, base64. |
| `manifest_NNN.signed.json` | Final signed manifest as it would appear in EXIF. |

If the Kotlin or Python JCS canonicalizer drifts, the
`test_jcs_vectors.py` tests fail. Don't blindly regenerate — find the drift.
